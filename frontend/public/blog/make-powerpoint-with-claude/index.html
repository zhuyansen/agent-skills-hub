How to Make a PowerPoint with Claude: Step-by-Step Tutorial (2026)

By Jason Zhu · November 18, 2026 · Tutorial · 8 min read

Short answer: Claude makes a real, editable .pptx with Anthropic's pptx skill. On Claude.ai's paid plans it is built in: ask for a PowerPoint and download it. In Claude Code, run /plugin marketplace add anthropics/skills and /plugin install document-skills@anthropic-agent-skills, then ask. In our test it turned a one-page brief into a 9-slide deck in 2.4 minutes.

Most PowerPoint tutorials teach you where the buttons are. This one is for the other way of working: you write what the deck should say, Claude builds the file, and you spend your time on the last 10% in PowerPoint. Everything below comes from a test we ran in October 2026, where Claude Code built the same deck with 32 different PPT skills and we graded every result.

The steps are the same either way. Claude Code shows more of what happens, so the tutorial follows it.

Step 1: Write a one-page brief

The single biggest difference between a deck you can use and one you redo is the brief. Ours fit on one page and said four things:

  • Who it is for and what they decide: "engineering managers deciding which open-source AI agent skills their team may install".
  • Length and tone: "8 to 10 slides. Clear, factual, no hype."
  • The sections, in order, each with its point.
  • Every number, exactly, including a small table.

Give Claude the numbers rather than letting it fill them in. In our test, 8 of the 28 skills that ran added at least one claim that was not in the brief. A brief with the real figures leaves less room for that, and makes it easy to check.

Step 2: Add the pptx skill (Claude Code)

Anthropic publishes the skill that powers Claude's file creation in anthropics/skills. In Claude Code:

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

That installs the pptx skill along with its Word, Excel and PDF siblings. On Claude.ai you can skip this step.

Step 3: Ask for the deck

Save the brief as brief.md in your project folder and ask for one file, with a check at the end:

Use the pptx skill to build the deck described in brief.md.
Save it as deck.pptx. Keep every number exactly as in the brief.
When it is done, render each slide to an image, look at them,
and fix anything cut off, overlapping or off the grid.

The last line matters. Asking Claude to look at its own slides catches the usual problems (a title that wraps onto three lines, a chart label running off the edge) before you open the file.

Step 4: Check the slides

Open the deck and go through it with five questions. They are the rubric we graded every deck on:

  1. Fundamentals: one idea per slide, readable type, nothing cut off.
  2. Design: one layout system the whole way through.
  3. Completeness: every section of the brief is there.
  4. Correctness: every number matches the brief.
  5. Fidelity: nothing added that the brief did not say.

Anthropic's pptx skill scored 96% on this rubric. Content was rarely where decks differed: 10 of the 28 decks scored 100%. What separated them was whether you could edit the result.

Step 5: Finish in PowerPoint

A native .pptx means every title, bullet, table and chart is a real PowerPoint object. Change a word, swap the theme colours, move a chart: it behaves like a deck you built by hand. Our test called this the editability level. The official skill reached level 2 (native text and shapes); the best-structured file, from ppt-master, reached level 3. Image-first skills sit at level 0: every slide is a picture.

Expect touch-ups, not a rebuild: Anthropic's deck needed only small fixes before we would hand it over.

Check a skill before you install it

A skill runs with your agent's permissions, so look it up first. Of the PPT skills our scan flagged CAUTION or UNSAFE, every one was flagged for how it installs (sudo, curl | sh), none for what it does while making slides. Paste any GitHub URL into the search box to see its grade.

FAQ

Can Claude make a PowerPoint?

Yes. Claude writes a real .pptx file with Anthropic's pptx skill. On Claude.ai's paid plans the skill is already there: ask for a PowerPoint and download the file. In Claude Code you add it once with /plugin install document-skills@anthropic-agent-skills.

Is the PowerPoint Claude makes editable?

With the pptx skill, yes: in our test it wrote native slides with real text boxes, tables and charts you can change in PowerPoint. Some community skills paint each slide as a picture instead; those look striking but you cannot change a word without redoing the slide.

How long does it take?

In our October 2026 test, Anthropic's pptx skill turned a one-page brief into a 9-slide deck in 2.4 minutes. Across the 28 PPT skills that ran, the range was about 2 to 16 minutes.

Which PPT skill is best for Claude?

It depends on who touches the deck next. For a PowerPoint a colleague will edit, ppt-master gave the most structured file; for slides you present in a browser, guizang-ppt-skill; for the quickest editable deck, Anthropic's own pptx skill or claude-office-skills. The full ranking is on our PPT skills page.

用 Claude 做 PowerPoint：一步步教程（2026）

作者 Jason Zhu · 2026 年 11 月 18 日 · 教程 · 约 8 分钟

简短回答：Claude 用 Anthropic 官方的 pptx skill 写出真正能改的 .pptx。Claude.ai 付费版自带，直接让它做 PPT 再下载；Claude Code 里先运行 /plugin marketplace add anthropics/skills 和 /plugin install document-skills@anthropic-agent-skills，再下指令。实测它把一页 brief 做成 9 页 deck 用了 2.4 分钟。

大多数 PowerPoint 教程教的是按钮在哪。这篇讲另一种做法：你写清楚这份 deck 要说什么，Claude 做出文件，你把时间花在最后 10% 的修改上。下面的内容都来自我们 2026 年 10 月的一次实测：同一份 brief，让 Claude Code 分别用 32 个 PPT skill 各做一份，逐份打分。

这是官方 pptx skill 按我们的 brief 做出来的 deck，没有改过：

用 Claude.ai 还是 Claude Code？

Claude.ai（付费版）Claude Code
准备不用：pptx skill 已内置装一次 skill（第 2 步）
适合偶尔做一份用本地文件做、经常做、想换别的 PPT skill
得到一个可下载的 .pptx文件夹里的 .pptx，加上生成它的脚本

两边步骤一样。Claude Code 能看到更多过程，所以下面按它来讲。

第 1 步：写一页 brief

一份能直接用的 deck 和一份要重做的 deck，最大的差别在 brief。我们的 brief 一页纸，写清了四件事：

  • 给谁看、他们要做什么决定："决定团队能装哪些开源 AI agent skill 的工程经理"。
  • 篇幅和语气："8 到 10 页，清楚、讲事实、不夸张"。
  • 按顺序列出每一节，以及每节要说明的点。
  • 所有数字，原样写出，包括一张小表格。

数字要你给，别让 Claude 自己补。实测跑通的 28 个 skill 里，有 8 个至少加了一条 brief 里没有的说法。brief 里写死真实数字，就少了这种空间，也方便核对。

第 2 步：装 pptx skill（Claude Code）

Claude 生成文件用的 skill，Anthropic 开源在 anthropics/skills。在 Claude Code 里运行：

/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

这会一起装上 pptx 以及 Word、Excel、PDF 三个 skill。用 Claude.ai 可以跳过这一步。

第 3 步：下指令

把 brief 存成项目文件夹里的 brief.md，只要一个文件，并在最后要求它自查：

用 pptx skill 按 brief.md 做这份 deck，存成 deck.pptx。
所有数字与 brief 保持一致。
做完后把每页渲染成图片看一遍，
修掉被截断、互相重叠或没对齐的地方。

最后一句很重要。让 Claude 看自己做的每一页，常见问题（标题折成三行、图表标签出界）在你打开文件前就修掉了。

第 4 步：检查每一页

打开 deck，用五个问题过一遍，这也是我们给每份 deck 打分的检查单：

  1. 基本功：一页一个意思，字看得清，没有被截断。
  2. 设计：从头到尾一套版式。
  3. 完整：brief 里的每一节都在。
  4. 正确：每个数字都和 brief 一致。
  5. 忠实：没有加 brief 里没说的内容。

官方 pptx skill 在这份检查单上拿了 96%。内容很少是拉开差距的地方：28 份 deck 里 10 份满分。真正拉开差距的，是做出来的东西能不能改。

第 5 步：在 PowerPoint 里收尾

原生 .pptx 意味着每个标题、要点、表格、图表都是真正的 PowerPoint 对象。改个字、换主题色、挪个图表，和你手做的 deck 一样。实测里我们把这叫可编辑性等级：官方 skill 到了 L2（原生文字和图形），结构最完整的 ppt-master 到了 L3；图片路线的 skill 是 L0，每页都是一张图。

预期是小修，不是重做：官方 skill 做的这份，小改几处就能交出去。

什么时候换别的 PPT skill

官方 skill 是合适的默认选择。我们收录的 205 个 PPT skill 走三条路线，各自适合不同的下一步：

这份 deck 接下来给…用实测

赶时间的人claude-office-skills原生（L2），小修即可，100%，3.2 分钟

完整排名、每份 deck 和每次运行的证据，都在 PPT skill 精选页。

装之前先查一下

skill 以你的 agent 的权限运行，所以先查一下。被我们标成 CAUTION 或 UNSAFE 的 PPT skill，全部是因为安装方式（sudo、curl | sh），没有一个是因为做幻灯片时的行为。在搜索框里粘贴任意 GitHub 链接就能看到它的评级。

常见问题

Claude 能做 PowerPoint 吗？

能。Claude 用 Anthropic 官方的 pptx skill 直接写出 .pptx 文件。Claude.ai 付费版已经自带这个 skill，直接让它做 PPT、下载文件即可；Claude Code 里用 /plugin install document-skills@anthropic-agent-skills 装一次就行。

Claude 做的 PPT 能改吗？

用 pptx skill 做的可以：实测里它写的是原生幻灯片，文本框、表格、图表都能在 PowerPoint 里直接改。有些社区 skill 是把每页画成一张图，看着好看，但改一个字就得重做那一页。

要多久？

2026 年 10 月的实测里，官方 pptx skill 把一页 brief 做成 9 页 deck 用了 2.4 分钟。跑通的 28 个 PPT skill，大约在 2 到 16 分钟之间。

哪个 PPT skill 最好？

看下一个碰这份 deck 的人是谁。要同事接着改的 PowerPoint，ppt-master 结构最完整；要自己在浏览器里讲的，guizang-ppt-skill；要最快拿到一份能改的，官方 pptx skill 或 claude-office-skills。完整排名在 PPT skill 精选页。

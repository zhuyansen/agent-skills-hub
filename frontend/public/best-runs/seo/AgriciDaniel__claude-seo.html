### Limitations the tool reported
- **seo-visual:** Playwright screenshots failed with `net::ERR_FAILED` on every URL, so there are no screenshots and no rendered above-the-fold check. Visual findings come from the HTML only.
- **seo-agentic:** the Lighthouse Agentic Browsing fraction wasn't measured. PSI cannot reach the sandbox (it returned HTTP 429), and the Playwright agent-UX check failed the same way.
- **seo-performance:** results come from a local Lighthouse lab run. All five pages scored 100, with LCP 0.6 s, CLS 0 and TBT 0 ms. INP can't be measured in the lab, and there is no CrUX field data.
- **No external data:** there is no Search Console, analytics, backlink, brand-mention or SERP-feature data for the site.

- Pages are static, server-rendered HTML with a viewport tag on every page. Real 404s are returned, with no soft 404s.
- Titles and descriptions are unique and a sensible length everywhere except `/guides/storing-tea/`.
- Bai Mudan Product schema is valid, and the visible prices match the schema.
- The writing is original and first-hand, with Flesch scores of 70–91 and no AI-pattern or filler signals.
- The address is the same everywhere (NAP consistency).
- Performance is excellent: tiny pages, no JavaScript or CSS, and width and height set on every image.

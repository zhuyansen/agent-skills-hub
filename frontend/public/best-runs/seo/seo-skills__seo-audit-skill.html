False claims (checked by hand)

  • schema-type: http://lumentea.test/ — No JSON-LD scripts contain a @type field (scriptsWithType=0)
    The home page JSON-LD is an array with @type Organization and WebSite.
  • schema-required-fields: http://lumentea.test/ — No recognized schema.org types found to validate
    The home page declares Organization and WebSite, both standard types; the report itself validates the Organization schema in another row.
  • content-duplicate-exact / content-duplicate-near: /teas is an exact duplicate (100% similar) of /shop
    /shop is not a separate page. It redirects (via /store/) to /teas/, so this is the same page, not duplicate content.
  • core-title-unique: Duplicate title found on 2 pages (/teas and /shop)
    /shop redirects to /teas/, so the 'All Teas' title appears on only one page.
  • content-duplicate-h1: /shop and /teas share the H1 'All our teas'
    /shop is a redirect to /teas/, not a second page with the same H1.
  • crawl-canonical-form-drift: Canonicals disagree on trailing-slash and no-trailing-slash paths
    Every canonical on the site uses the trailing-slash form (e.g. /about/, /teas/bai-mudan/, /).

# SEO Audit: http://lumentea.test/ (Lumen Tea)

Tool: `seo-audit` skill (~/.claude/skills/seo-audit), following its audit framework and output format.
Date: 2026-11-11. Method: crawl of robots.txt, sitemap.xml, every sitemap URL and every internal link with curl; HTML head, headings, links, images and JSON-LD inspected (JSON-LD is inline in the static HTML, so it was visible to curl).
Scope notes: HTTP-only is ignored per instructions (no HTTPS findings). No Search Console, analytics, PageSpeed/CWV field data, or keyword data are available for this private site, so those checks were not run. No product-marketing context file existed; skill defaults used (full site, technical + on-page + content).

## Executive Summary

Small e-commerce site (10 sitemap URLs, 8 live HTML pages). Copy quality is good, but several crawl/indexation errors block the most important commercial pages:

1. **Best-selling product page is noindexed** (/teas/jasmine-silver-needle/).
2. **Category page /teas/ canonicalises to the homepage**, so it will drop out of the index.
3. **robots.txt blocks /blog/**, hiding the only content/traffic-driving article.
4. **Main nav "Shop" link goes through a 2-hop redirect chain** (/shop/ → /store/ → /teas/).
5. **Sitemap lists a 404, a noindexed URL and robots-blocked URLs**; a guide page is orphaned.

Quick wins: remove the noindex, fix the /teas/ canonical, delete `Disallow: /blog/`, point nav at /teas/, add the missing title / H1 / viewport / alt text, fix the invalid Product JSON-LD.

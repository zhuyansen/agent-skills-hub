The same task for every tool: audit a 9-page test shop at http://lumentea.test/, served inside a throwaway sandbox, with 16 planted SEO problems. Claude Code (Claude Opus 5.5) installed the tool from its README and ran its audit; a judge (Claude Opus 5.5, three passes, given the whole site) marked the report, and every false claim was checked by hand. Repo commit bd4921e12b82. All results · The test site · Task

Found 12 of 16 planted problems; 0 false claims about the site; 16 problems raised in all; 1 min.

It obeys robots.txt, so it did not read the two blog pages the test blocks and missed the four problems on them; it did report the block. Its MCP crawl failed with a parameter error (Unrecognized key: "saveReport"), so the run used its CLI, which needed no account.

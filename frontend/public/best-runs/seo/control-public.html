# SEO Audit: Lumen Tea (https://lumentea-test.vercel.app/)

Audit date: 2026-11-11. Method: I crawled every URL in the sitemap and every internal link (with curl and a Python crawler). For each URL I checked the status codes, redirects, response headers (including X-Robots-Tag), robots.txt, sitemap.xml, `<head>` metadata, headings, images, internal links, hreflang and JSON-LD. Search Console, analytics and keyword data were not available, so all findings come from the crawl.

Pages crawled: 10 sitemap URLs and 5 additional URLs found through links (/shop/, /store/, /zh/, /teas/dragon-well/, images).

## High severity

### 1. Best-selling product is noindexed
- **URL:** https://lumentea-test.vercel.app/teas/jasmine-silver-needle/
- **Problem:** `<meta name="robots" content="noindex, follow">` is in the `<head>`. The homepage calls this tea "our best seller", but search engines will drop it from the index. The page is also in the sitemap, so the signals contradict each other.
- **Fix:** Remove the robots meta tag (or set it to `index, follow`).

### 2. Bai Mudan product page is noindexed through an HTTP header
- **URL:** https://lumentea-test.vercel.app/teas/bai-mudan/
- **Problem:** The server sends the response header `X-Robots-Tag: noindex`. You can't see it in the HTML, so it is easy to miss. As a result, both of the shop's two products are kept out of the index.
- **Fix:** Remove the header from the hosting config (for example the `headers` setting in vercel.json or the middleware).

### 3. Category page canonicalises to the homepage
- **URL:** https://lumentea-test.vercel.app/teas/
- **Problem:** `<link rel="canonical" href="https://lumentea-test.vercel.app/">` tells Google that /teas/ is a duplicate of the homepage, so the main product listing will probably not be indexed. Its `og:url` correctly says /teas/, which contradicts the canonical.
- **Fix:** Set the canonical to `https://lumentea-test.vercel.app/teas/`.

### 4. robots.txt blocks the whole blog
- **URLs:** https://lumentea-test.vercel.app/robots.txt, which affects /blog/ and /blog/how-to-brew-green-tea/
- **Problem:** `Disallow: /blog/` stops crawlers from fetching the journal, including the brewing guide, which is the site's main content asset for informational searches. Both blog URLs are also in the sitemap, which contradicts the block.
- **Fix:** Remove the `Disallow: /blog/` line (or narrow it to whatever path actually needs to be blocked).

### 5. Blog post has no `<title>`
- **URL:** https://lumentea-test.vercel.app/blog/how-to-brew-green-tea/
- **Problem:** The page has no `<title>` element, so search engines will make up their own title for the result.
- **Fix:** Add a title, for example `How to Brew Green Tea Without the Bitterness | Lumen Tea`.

## Medium severity

### 6. Invalid Product structured data
- **URL:** https://lumentea-test.vercel.app/teas/jasmine-silver-needle/
- **Problem:** The JSON-LD block has trailing commas (`"availability": "...InStock",}` and `},\n}`), so it is not valid JSON. The parse fails at line 3, column 118. The Product and Offer markup will be ignored, so the page cannot get rich results such as price and availability.
- **Fix:** Remove the trailing commas and check the result in Google's Rich Results Test.

### 7. Contact page has no H1
- **URL:** https://lumentea-test.vercel.app/contact/
- **Problem:** The page starts with `<h2>Get in touch</h2>` and has no `<h1>`.
- **Fix:** Change it to `<h1>Contact Lumen Tea</h1>` (or similar).

### 8. Main navigation link goes through a redirect chain
- **URL:** Header nav on every page → https://lumentea-test.vercel.app/shop/
- **Problem:** /shop/ returns a 301 to /store/, which returns a 301 to /teas/. The most important nav link wastes crawl budget, loses a little link equity at each hop and slows users down.
- **Fix:** Point the nav link straight to `/teas/`, and make /shop/ and /store/ each redirect to /teas/ in one hop.

### 9. Broken internal link
- **Source:** https://lumentea-test.vercel.app/blog/how-to-brew-green-tea/
- **Target:** https://lumentea-test.vercel.app/teas/dragon-well/ (returns 404)
- **Fix:** Remove the link until the product exists, or link to a "coming soon" page that returns 200.

### 10. hreflang points to a missing page
- **URL:** https://lumentea-test.vercel.app/ (homepage)
- **Problem:** `<link rel="alternate" hreflang="zh-CN" href=".../zh/">`, but /zh/ returns 404. There is also no self-referencing `hreflang="en"` and no `x-default`, so the hreflang set is invalid even if /zh/ existed.
- **Fix:** Remove the tag until a Chinese version exists. When it does, add reciprocal en, zh-CN and x-default annotations on both versions.

### 11. Sitemap lists a 404 URL
- **URL:** https://lumentea-test.vercel.app/sitemap.xml → https://lumentea-test.vercel.app/teas/white-peony/ (404)
- **Problem:** White Peony is the same tea as Bai Mudan (/teas/bai-mudan/). The old or alternative URL is in the sitemap but does not resolve.
- **Fix:** Remove it from the sitemap and 301-redirect /teas/white-peony/ to /teas/bai-mudan/, because people do search for "white peony tea".

### 12. Sitemap includes URLs that cannot be indexed
- **URL:** https://lumentea-test.vercel.app/sitemap.xml
- **Problem:** The sitemap includes /teas/jasmine-silver-needle/ (meta noindex), /teas/bai-mudan/ (X-Robots-Tag noindex), and /blog/ and /blog/how-to-brew-green-tea/ (blocked by robots.txt). It should list only canonical URLs that return 200 and can be indexed.
- **Fix:** Fixing issues 1, 2 and 4 resolves this. Otherwise, keep these URLs out of the sitemap.

### 13. Duplicate title
- **URL:** https://lumentea-test.vercel.app/guides/storing-tea/
- **Problem:** The title and og:title are `Lumen Tea | Small-Batch Loose Leaf Tea from Fujian`, the same as the homepage, and say nothing about the page's subject.
- **Fix:** Use something like `How to Store Loose Leaf Tea | Lumen Tea`.

### 14. Orphan page
- **URL:** https://lumentea-test.vercel.app/guides/storing-tea/
- **Problem:** No page on the site links to this guide. It can only be found through the sitemap, so it gets no internal link equity. It also sits in a separate /guides/ section, while the other guide lives under /blog/.
- **Fix:** Link to it from the journal index, the product pages (storage and harvest date) and the footer. Consider moving it under /blog/ for consistency.

### 15. Blog index has the wrong (duplicated) meta description
- **URL:** https://lumentea-test.vercel.app/blog/
- **Problem:** The meta and OG description ("Browse every loose leaf tea we sell…") is copied word for word from /teas/ and does not describe the journal.
- **Fix:** Write a unique description, for example "Brewing guides and notes from the Fujian farms we buy from…".

### 16. Blog index has no viewport meta tag
- **URL:** https://lumentea-test.vercel.app/blog/
- **Problem:** `<meta name="viewport" ...>` is missing, so the page shows as a zoomed-out desktop layout on phones. With mobile-first indexing, this hurts the page.
- **Fix:** Add `<meta name="viewport" content="width=device-width, initial-scale=1">`.

## Low severity

### 17. Image has no alt text
- **URL:** https://lumentea-test.vercel.app/teas/jasmine-silver-needle/
- **Problem:** `<img src="/img/jasmine.png" width="800" height="800">` has no alt attribute. This is bad for accessibility and for image search.
- **Fix:** Add descriptive alt text, for example "Jasmine Silver Needle white tea buds".

### 18. Title promises a product that isn't sold
- **URL:** https://lumentea-test.vercel.app/teas/
- **Problem:** The title is "All Teas | White, Green and Jasmine Tea", but the page (and the homepage) says only two white teas are sold. Searchers looking for green tea will be disappointed.
- **Fix:** Use something like `All Teas | White and Jasmine Tea from Fujian | Lumen Tea`.

### 19. Sitemap lastmod values are not informative
- **URL:** https://lumentea-test.vercel.app/sitemap.xml
- **Problem:** All 10 URLs have `lastmod` 2026-10-01, including a blog post published 2026-09-12. When every date is the same, Google tends to ignore them.
- **Fix:** Use each page's real modification date.

### 20. /index.html serves a duplicate homepage
- **URL:** https://lumentea-test.vercel.app/index.html
- **Problem:** It returns 200 with the same content as /. The canonical tag points to /, which limits the impact.
- **Fix:** 301-redirect /index.html to /.

### 21. No /favicon.ico
- **URL:** https://lumentea-test.vercel.app/favicon.ico (404)
- **Problem:** A `<link rel="icon">` points to /img/icon.png, which is 64×64 and works. However, some crawlers and browsers request /favicon.ico directly. Google also recommends an icon size that is a multiple of 48px.
- **Fix:** Add /favicon.ico and a 48×48 (or larger multiple) icon.

### 22. Incomplete Product structured data
- **URLs:** https://lumentea-test.vercel.app/teas/bai-mudan/ and /teas/jasmine-silver-needle/
- **Problem:** Product has no `brand` or `url`, and Offer has no `url`, `priceValidUntil` or `shippingDetails`/`hasMerchantReturnPolicy`. The site already states the free UK shipping over £30 and the 30-day refund policy, so this data exists. Merchant-listing rich results are limited without these fields.
- **Fix:** Add these properties.

### 23. Generic or missing sharing image and structured data on secondary pages
- **URLs:** /about/, /contact/, /teas/, /blog/, /guides/storing-tea/
- **Problem:** All of these use the homepage hero as og:image (/about/ has its own team.png but doesn't use it). /contact/, /teas/, /blog/ and /guides/storing-tea/ have no JSON-LD. A LocalBusiness or Store block would suit /contact/, which has an address, phone number and opening hours. An ItemList or BreadcrumbList would suit /teas/. An Article would suit the storage guide. No page has breadcrumb markup.
- **Fix:** Add page-specific og:image values and the relevant schema types.

### 24. BlogPosting schema is incomplete
- **URL:** https://lumentea-test.vercel.app/blog/how-to-brew-green-tea/
- **Problem:** It has no `publisher`, `dateModified` or `mainEntityOfPage`.
- **Fix:** Add these properties.

## Checks that passed
- HTTP redirects to HTTPS with a 308. HSTS is enabled.
- URLs without a trailing slash redirect to the trailing-slash version with a 308.
- Unknown URLs return a real 404 with `noindex` (no soft 404s).
- The homepage, /about/, the product pages and the brewing guide have unique, descriptive titles and meta descriptions. Apart from issue 15, the descriptions are a sensible length.
- Every page except /contact/ has exactly one H1.
- Images have explicit width and height (no layout shift), and their declared dimensions match the actual image sizes.
- The Organization and WebSite JSON-LD on the homepage is valid.
- `<html lang="en">` is set on all pages.

The session's closing message

I audited all 15 URLs on the site, including the 10 in the sitemap, and found 24 SEO problems: 5 high, 11 medium and 8 low severity. The full report, with the page URL, severity and a suggested fix for each, is in `~/work/output/report.md`. I didn't change anything on the site.

The high-severity problems are:
1. **Jasmine Silver Needle product page is hidden from search.** It has a `noindex` meta tag, even though the homepage calls it the best seller.
2. **Bai Mudan product page is hidden from search too.** The server sends an `X-Robots-Tag: noindex` header, which you can't see in the HTML. Between 1 and 2, neither of the shop's two products can appear in Google.
3. **The /teas/ category page points its canonical at the homepage.** That tells Google /teas/ is a duplicate, so it probably won't be indexed.
4. **robots.txt blocks the whole blog** (`Disallow: /blog/`), including the brewing guide, even though both blog URLs are in the sitemap.
5. **The brewing guide has no `<title>`.**

The medium-severity problems:
- **Invalid product markup:** the structured data on the Jasmine page doesn't parse (trailing commas), so it can't get price or stock rich results.
- **Missing H1:** the contact page has none.
- **Redirect chain:** the "Shop" link on every page goes through two redirects before reaching /teas/.
- **Broken link:** the brewing guide links to /teas/dragon-well/, which returns 404.
- **Broken hreflang:** the homepage points to a Chinese version at /zh/, which returns 404.
- **Sitemap errors:** it lists a 404 (/teas/white-peony/) and pages that are blocked or set to `noindex`.
- **Storage guide:** it reuses the homepage's title, and no page links to it.
- **Journal page (/blog/):** its meta description is copied from /teas/, and it has no viewport tag, so it won't display properly on phones.

The low-severity items are smaller fixes: a missing alt attribute, a title that mentions green tea the shop doesn't sell, identical sitemap dates, a duplicate /index.html, a missing /favicon.ico, and incomplete structured data.

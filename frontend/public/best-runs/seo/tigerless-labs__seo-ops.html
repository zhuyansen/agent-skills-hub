The same task for every tool: audit a 9-page test shop at http://lumentea.test/, served inside a throwaway sandbox, with 16 planted SEO problems. Claude Code (Claude Opus 5.5) installed the tool from its README and ran its audit; a judge (Claude Opus 5.5, three passes, given the whole site) marked the report, and every false claim was checked by hand. Repo commit 777bde405d2d. All results · The test site · Task

Found 13 of 16 planted problems; 2 false claims about the site; 24 problems raised in all; 2 min.

30 fixed checks. It passed "robots.txt allows AI crawlers" and "redirect hops ≤1" although the blog is blocked for every crawler and the main menu link takes two hops.

False claims (checked by hand)

  • C1 (robots.txt allows AI crawlers) passes: "all 18 UAs allowed"
    robots.txt has User-agent: * Disallow: /blog/, which blocks every crawler, AI crawlers included, from the whole blog.
  • C20 (redirect hops ≤1) passes: "10/10 pages pass" / no chained redirects
    The Shop link in the navigation on every page goes to /shop/, which redirects 301 to /store/ and then 301 to /teas/. That is a two-hop redirect chain.

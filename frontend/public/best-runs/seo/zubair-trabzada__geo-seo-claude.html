# GEO Audit Report: Lumen Tea

**Audit Date:** 2026-11-11
**URL:** http://lumentea.test/
**Business Type:** E-commerce (small online tea shop, Bristol, UK; two products, plus a Saturday collection point)
**Pages Analyzed:** 9 fetched (7 HTML content pages, 2 × 404, 2 × 301 redirects). 2 URLs were not fetched because robots.txt disallows them (/blog/, /blog/how-to-brew-green-tea/).
**Tool:** geo-seo `geo-audit` skill. Phase 1 crawl, then the five specialist subagents (geo-technical, geo-schema, geo-content, geo-ai-visibility, geo-platform-analysis).

> Audit constraints: the site is served over plain HTTP only because the sandbox has no certificate, so HTTPS/HSTS were excluded. The site is not on the public internet, so off-site checks (brand mentions on Reddit/YouTube/LinkedIn, Search Console, Bing Webmaster Tools, PageSpeed/CrUX) had no data. Those items are scored on the absence of evidence, not on confirmed absence. A Wikipedia API search for "Lumen Tea" found no entity.

## Executive Summary

**Overall GEO Score: 38/100 (Critical)**

The writing is strong and first-hand: named farms, harvest dates, exact brewing figures. The site is static, server-rendered HTML with no JavaScript, so every crawler sees the full content. Indexability blocks most of that value from search and AI systems:
- Both product pages are noindexed: one by a meta tag, one by an `X-Robots-Tag` header.
- robots.txt blocks the whole /blog/ Journal, including the brewing guide.
- The /teas/ listing canonicalises to the homepage.
- The best-seller's Product JSON-LD does not parse.

Off-site entity signals are also missing: no `sameAs`, no reviews, no verifiable brand presence.

## Critical Issues (Fix Immediately)

1. **The best-selling product page is noindexed by a meta tag.** [T Critical, P Critical, A High]
   - **URL:** http://lumentea.test/teas/jasmine-silver-needle/
   - **Problem:** The page has `<meta name="robots" content="noindex, follow">`, which drops it from Google and Bing and so from AI Overviews, Gemini, Copilot and ChatGPT search. It also holds the site's most citable passage (score 63).
   - **Fix:** Remove the tag, or set it to `index, follow`.
2. **The second product page is noindexed by an HTTP header.** [T Critical, P Critical, A High]
   - **URL:** http://lumentea.test/teas/bai-mudan/
   - **Problem:** The server sends `X-Robots-Tag: noindex`, which is not visible in the HTML. With issue 1, neither of the shop's only two products can be indexed.
   - **Fix:** Remove the header from the server or CDN config, and check that no other path gets it.
3. **robots.txt blocks the whole Journal for every crawler.** [T Critical, P Critical, C High, A Medium (partial AI-crawler blocking)]
   - **URLs:** http://lumentea.test/blog/ and http://lumentea.test/blog/how-to-brew-green-tea/
   - **Problem:** `Disallow: /blog/` blocks the main editorial and expertise content (the brewing guide). The section is linked from the main nav, the homepage and /teas/, and is listed in sitemap.xml.
   - **Fix:** Remove the line, or narrow it to specific paths, for example `/blog/drafts/`.

## High Priority Issues

4. **/teas/ canonicalises to the homepage.** [T High, P High, A Medium]
   - **URL:** http://lumentea.test/teas/
   - **Problem:** It has `<link rel="canonical" href="http://lumentea.test/">`, which contradicts its `og:url`, so search engines will fold the listing page into the homepage.
   - **Fix:** Make the canonical point to `http://lumentea.test/teas/`.
5. **The Product JSON-LD on the best-seller is invalid.** [T High, P High, S Medium (raised from Low because the whole block fails), A Medium]

   - **Problem:** Trailing commas after `"availability": "https://schema.org/InStock",` and after the `offers` object mean the whole block fails to parse.
   - **Fix:** Remove both commas and run the block through a validator.
6. **No llms.txt.** [A High, P Low]
   - **URL:** http://lumentea.test/llms.txt
   - **Problem:** It returns 404, and there is no llms-full.txt either.

## Critical Issues (Fix Immediately)

1. **The best-selling product page is noindexed by a meta tag.** [T Critical, P Critical, A High]
   - **URL:** http://lumentea.test/teas/jasmine-silver-needle/
   - **Problem:** The page has `<meta name="robots" content="noindex, follow">`, which drops it from Google and Bing and so from AI Overviews, Gemini, Copilot and ChatGPT search. It also holds the site's most citable passage (score 63).
   - **Fix:** Remove the tag, or set it to `index, follow`.
2. **The second product page is noindexed by an HTTP header.** [T Critical, P Critical, A High]
   - **URL:** http://lumentea.test/teas/bai-mudan/
   - **Problem:** The server sends `X-Robots-Tag: noindex`, which is not visible in the HTML. With issue 1, neither of the shop's only two products can be indexed.
   - **Fix:** Remove the header from the server or CDN config, and check that no other path gets it.
3. **robots.txt blocks the whole Journal for every crawler.** [T Critical, P Critical, C High, A Medium (partial AI-crawler blocking)]
   - **URLs:** http://lumentea.test/blog/ and http://lumentea.test/blog/how-to-brew-green-tea/
   - **Problem:** `Disallow: /blog/` blocks the main editorial and expertise content (the brewing guide). The section is linked from the main nav, the homepage and /teas/, and is listed in sitemap.xml.
   - **Fix:** Remove the line, or narrow it to specific paths, for example `/blog/drafts/`.

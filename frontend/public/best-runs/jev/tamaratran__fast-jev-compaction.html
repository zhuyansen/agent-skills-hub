Steps the README does not mention

  • Had to create a project to install into (npm init -y). The package is ESM-only, so the script has to be .mjs or the project needs "type": "module".
  • The README example is TypeScript with an 'import type'. Running it needs tsx or tsc, which the README doesn't mention for library users. I used plain JS (.mjs) and dropped the type import.
  • The README transcript is incomplete ('// …'). As written it has 3 messages with preserveRecentMessages: 4, so every call is pinned and Jev would never be asked. I had to write extra messages (5 tool calls in total) to get a real Jev call.
  • Version mismatch: npm installs fast-jev-compaction 0.4.1, but the repo at ~/src is 0.2.0. The published package also ships files the repo doesn't have: cli/*.mjs, cli/jev-gate.py with a committed __pycache__ .pyc, SKILL.md, plugins/ and test dumps. So what users install is not the source in this checkout.

**What the page will do** (full spec: `specs/001-expense-tracker/spec.md`):

1. **记一笔**：填"花了多少（元）"和"买了什么"，点"记一笔"。新记录排在列表最上面，自动记下日期和时间。

6. 双击就能打开，不用装任何东西，也不用注册账号。手机屏幕上也能用。

**这一版不做**：分类、按月统计、修改已有记录、导出、多台设备同步。另外，如果清除了浏览器数据，记录会丢失。

  1. The spec is written. Spec Kit's workflow has a review step here: you approve the spec before it moves on to planning. So I'm stopping to ask you.

**Spec: 家庭记账本** (full text in `specs/001-family-ledger/spec.md`)

1. **记账（最重要）**：记收入或支出，包括金额、类别、日期（默认今天）、备注（选填，最多 200 字）。记录可以修改，也可以删除，删除前会先问你确认。金额写错时（比如空着、写 0、负数、超过两位小数）会用中文提示。关掉网页再打开，记录还在。
2. **按月汇总（最重要）**：选一个月，看总收入、总支出、结余。结余是负数时会标红。可以切换上个月和下个月，下面列出当月的所有记录。
3. **类别花费**：当月每个支出类别花了多少、占百分之几，从多到少排，并配一张图。
4. **预算提醒**：可以设一个每月总预算，也可以给单个类别设预算，每个月都按这个数算。花到 80% 时提示"接近预算"。超了会马上弹出提醒，并写明超了多少钱。
5. **导出 Excel**：导出本月或全部记录，生成 .xlsx 文件，列是 日期、类型、类别、金额、备注。金额是数字，可以直接求和。

**我替你定好的默认设置：**
- **类别**：支出有 餐饮、交通、购物、居住、水电煤、通讯、医疗、教育、娱乐、人情、其他；收入有 工资、奖金、理财、兼职、其他。你也可以自己加类别。
- **使用范围**：只用人民币，一个家庭在一台电脑上用，不用注册账号。
- **数据**：只存在你的电脑上，不会联网。如果清除了浏览器数据，记录就没了，所以导出的 Excel 也可以当备份用。
- **这一版没有**：从 Excel 导入、周期性记账（比如每月自动记房租）。

**可以按这个规格开始做计划吗？** 回答"批准"就继续；想改什么，直接告诉我。

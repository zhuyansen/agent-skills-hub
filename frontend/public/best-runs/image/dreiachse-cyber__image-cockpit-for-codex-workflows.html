How it went (the session's closing message)

All six pictures are in `~/work/output/`. I looked at each one and they match the brief.

**What the tool is.** The installed tool in `~/src` is Image Cockpit, a pixel-art app. It doesn't make images itself: it writes a job file and expects Codex to make the picture. Codex isn't on this machine, so I started its local server (port 8787 was taken, so I used 8799) and created the jobs through it. Then I did Codex's part: for each job I called OpenAI's image API with the job's prompt, negative prompt, notes and size, and saved the result to the tool's outbox. Because the tool only does pixel art, all six are in a warm pixel-art style.

- **`poster.png`**: a sourdough loaf on a board in morning light by a bakery window. All six lines are there, spelled correctly, including the `·` separators, the `£` prices and both Chinese lines, with no other text.
- **`product.png`**: a kraft-paper bag with a sourdough loaf peeking out the top, on a light-grey background. "Morning Loaf" is printed on it in dark brown and there's no other text.
- **`mascot-1.png` to `mascot-4.png`**: Bun waving from the front, running left seen from the side, carrying a tray of three croissants, and asleep in a wicker basket. I made mascot-1 first, then made the other three as edits of mascot-1 using the tool's image-edit mode. That keeps the body, face, rosy cheeks, white chef's hat and red scarf the same in all four. None of them has any text.

The skill could not meet one part of the brief: `poster.png` is 2:3 (1024×1536), not 3:4, because the tool only offers 1024×1024, 1536×1024 and 1024×1536.

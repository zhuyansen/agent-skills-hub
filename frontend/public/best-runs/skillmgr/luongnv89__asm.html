On loading skills only when needed, the tool's docs say: README 'Attention budget': every installed skill's frontmatter description is resident in the agent's prompt on every message; the full SKILL.md body is only paid when the skill fires. asm does not change that loading itself. It measures it (asm stats --tokens, asm audit residency) and offers ways to avoid residency: asm get <skill> prints a body on demand with no install, and asm install --library / asm deactivate / asm disable keep skills out of resident context.

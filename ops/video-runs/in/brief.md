# Brief: a 15-second promo video for Tidepool

Tidepool is an app that tells swimmers whether the water at their local beach is clean enough to swim in today.
Make a 15-second promo for it. Use the on-screen copy below exactly, in this order; the look and the motion are yours.

## On-screen copy, in order

1. Know before you swim.
2. Water quality at 2,400 beaches, checked every morning.
3. Good. Fair. Stay out.
4. Rain warnings tell you how long to wait.
5. Tidepool. Check my beach.

## Requirements

- One file: `video.mp4`, H.264, 1920 x 1080, 30 frames per second, 15 seconds long (14.5 to 15.5 is fine).
- Every line of the copy is on screen long enough to read. No other sentences, taglines, logos of real companies or claims.
- No voice-over. Music or sound is optional; if you add any, make it in code or with tools already on this machine.
- No stock footage or downloaded images are needed: draw with code, shapes, type and colour.
- This machine has Node 22, Python 3, Chromium (/usr/bin/chromium) and ffmpeg. There are no API keys for video, image or voice models.

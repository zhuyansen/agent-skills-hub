# 新站冷启动 TODO 清单(通用版 · 水系模型 v4 配套 · 2026-07)

> 给任何新站的落地清单。原则:先接数据表,再开进水口,AI 火力别浪费在撑子页。全程零付费也能跑通(付费项都标了 💰)。

## Day 0:建站前(做错了后面全白干)

- [ ] **域名避两刀**:别用不受信 TLD(.top/.xyz 收录慢),别拿"类目描述词"当站名(品牌权重上不去);买前 virustotal + `site:` 查域名黑历史
- [ ] **渠道四问先分诊**:用户会主动搜吗?能几秒演示秒懂吗?依赖情绪/信任吗?能被说成一个搜索词吗?——答案不利就别把 SEO 当主渠道
- [ ] **架构一次定型**:hub → cluster → 子页;URL 规范定死(https + 无 www + 尾斜杠统一),以后每条外链都按这个格式给
- [ ] **KGR 选词冷启动**:`allintitle:` 结果数 ÷ 月搜索量 < 0.25 才做;新站第一天没有 GSC 数据,靠 KGR 顶上

## Week 1:数据分析套件(免费四件套,管道建好≠水会流)

- [ ] **GSC**:验证域名 + 提交 sitemap;>1000 页分批提交
- [ ] **GA4**:装好后**立刻标关键事件**(注册/复制安装命令/订阅/checkout)——它是日后投流和转化验证的硬前置,别拖
- [ ] **Bing Webmaster**:从 GSC 一键导入;开 **IndexNow**(新页秒级推送);免费送五样:竞品外链查询 / Keyword Research / Site Scan / Index Explorer / **AI Performance**
- [ ] **Microsoft Clarity**:热图 + 死点击 + **AI Visibility Citation**(用 GSC 授权开通,看"哪些 AI 在引用你、用什么词"——这是免费的 GEO 水位表)
- [ ] **Ahrefs Webmaster Tools**(免费版):DR/引用域基线 + Site Audit(5000 页采样)+ AI responses 面板
- [ ] 记一张**基线表**:DR、引用域、收录数、品牌词位次——以后每月对账,历史行不改

## Week 1-2:让 AI 引用你(GEO 基建)

- [ ] **llms.txt**:站根放一份,给 AI 引擎的站点说明书(核心页面清单 + 一句话定位)
- [ ] **robots.txt 放行 AI 爬虫**:GPTBot / ClaudeBot / PerplexityBot / Bingbot——想被引用就别拦
- [ ] **结构化数据**:Organization + WebSite + 内容页对应 schema;实体图 sameAs 绑上 GitHub/npm/LinkedIn/X
- [ ] **预渲染/SSR 检查**:AI 爬虫大多不执行 JS,`curl` 你的核心页,首包 HTML 里必须有完整内容
- [ ] **备"可被提及"的资产**(被提及 > 被链接,相关性 0.737 vs 0.28):开源仓库、公开数据集、可复述的数据结论("我们扫了 X 个样本,Y% 有问题")、YouTube/播客露出
- [ ] **场景页承接自然语言查询**:AI 引擎爱引 "best/free X tools for Y" 型页面——建 2-3 个真实对比页,别堆词
- [ ] 30 天后回看 **Bing AI Performance + Clarity Citation**:AI 引用量通常是 AI 点击量的许多倍("被引未点击"),别只盯 GA

## Week 2-4:进水口(外链两层论)

- [ ] **发现层**(免费,一次性铺完就收手):向 10-20 个垂类目录/awesome 列表提交,目的是触发收录和进入 AI 抓取语料——**不传权重,别持续堆量**
- [ ] **权重层**(💰可选):垂类客座博客,日 1-2 条封顶;投前 10 秒过 8 项清单(真实流量/近期收录/DR/运营时长/相关性/dofollow/出链少/发达国家)
- [ ] **零成本高 DR 三招**:Notion 公开页挂链(开"允许搜索引擎索引")、Stripe Climate/捐赠公开页、Trustpilot 主页——当增量,别信"一条链拉 DR 到 30"
- [ ] **GitHub 正确用法**:300 星换 dofollow 是谣言;真实价值 = 垂类导流(自己的工具 repo + 找相关仓库谈 README 位置换)
- [ ] 🚫 **生存红线**:有偿求链被查 = 整站 K;买榜/买票/买星 = 封号 + 品牌塌方

## 持续:内容与转化

- [ ] **内链先于外链**:每个要冲排名的页,先保证首页/频道页有内链指过去;孤儿页 = 断管
- [ ] **活水**:一条带日期的内容流(日报/更新日志),配断流自动告警;零供给新词拼速度,建页 SLA 24-48h
- [ ] **转化埋点验证**:上线一周内亲手触发每个关键事件,GA 实时报表里看到才算通
- [ ] **回流钩子**:邮件订阅/变更告警,把流过的水收回水库

## 每周一 30 分钟巡检(四问)

1. 进水口开了吗?(新增引用域/AI 引用)
2. 水蓄得住吗?(品牌词位次)
3. 水在流吗?(孤儿页/收录比)
4. 水做功吗?(关键事件数)

> 预期管理:曝光≠排名,真排名周期 ~180 天;前 3 个月看收录和 AI 引用,别看排名焦虑。

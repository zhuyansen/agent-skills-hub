# N / M / X 基线(2026-10-14)

N = 我们生成的可收录网址数,M = Google 已编入索引数,X = Google 知道的网址数。
来源:N 取自 10-14 最近一次成功部署的构建日志;M、X 和抓取数据读自 Search Console 后台
"网页索引编制"和"抓取统计信息"两个报告(网页上读数,未下载文件)。下个月同日再记一次。

## 三个数

| | 数量 | 说明 |
|---|---:|---|
| **N 可收录网址** | **约 19,600** | skill 14,693 · audit 4,208 · 作者页 500 · daily 94 · 场景页约 35 · 蓝皮书 17 · compare 11 · 分类 9 · 博客 9 · 静态页约 6 |
| 其中提交进站点地图 | 约 4,050 | skill 3,867(500 星以上)+ 其余类型;50–499 星的 10,826 个 skill 页、audit、作者页有意不提交 |

**N 远大于 X**:约 1.36 万个可收录网址 Google 还不知道。**X 也明显大于 M**:Google 知道的网址里有 2,630 个没收录。

## 抓取(近 90 天)

| 指标 | 数值 |
|---|---|
| 抓取请求总数 | 1.56 万(约 173 次/天) |
| 其中 HTML | 63%(约 1.0 万次,约 110 个网页/天) |
| 目的 | 刷新 60% · 发现 40% |
| 响应 | 200 占 92% · 301 占 5% · 404 占 3% |
| 平均响应时间 | 68 毫秒,托管 90 天无问题 |
| 下载量 | 1.44 亿字节 |

按每天约 110 个 HTML 网页计算,把 N 全部抓一遍要约 180 天,而且其中 60% 的抓取用在刷新已知网页上。
响应快、托管无问题,所以抓取量少不是服务器的原因,是 Google 分给这个站的抓取预算本身就小。

# 收录健康度：N / M / X 全盘整理（2026-10-14）

起因:一条讲 SEO 信息架构的帖子——先做关键词研究,再把关键词映射到 URL,按业务定 URL 层级;
并且必须知道三个数:**N 计划收录的网址、M Google 实际收录的网址、X 爬虫看到的网址**。
"绝大部分大型网站的 SEO 出问题,都是因为这三个数字失去控制。"

本文把今天围绕这件事查到的数据、做的改动、没做的决定和之后要看的指标放在一处。
原始数字见 [nmx-2026-10-14.md](nmx-2026-10-14.md)。

N 的构成:skill 页 14,693(其中 50–499 星 10,826、500 星以上 3,867)· audit 4,208 · 作者页 500 · daily 94 · 场景页约 35 · 蓝皮书 17 · compare 11 · 分类 9 · 博客 9 · 静态页约 6。

**结论:N ≫ X > M。** 约 1.36 万个可收录网址 Google 根本不知道;知道的里面又有 2,630 个没收录。

## 二、三个数失控的七种情况

| 情况 | 含义 | 常见原因 | 我们站 |
|---|---|---|---|
| **X ≪ N** | 计划的页面爬虫没找到 | 孤立页、层级深、站点地图缺失、抓取预算小 | **最严重**:19,600 vs 6,000 |
| **M ≪ X** | 抓了不收 | 模板薄、近似重复、软 404、页面没有额外价值 | 936 个"已抓取未收录" + 74 个软 404 |
| **X ≫ N** | 爬虫看到大量没计划的网址 | 参数网址、无限翻页、坏链接 | 947 个参数网址(robots 已挡)、404 有 158、重定向 135 |
| **M > N** | 收录了不想要的页面 | 参数、大小写、http/https、预览域名、改名未跳转 | 很少:8 个被 robots 挡却仍被收录 |
| **M ≈ N 但没流量** | 收录了没人搜 | 关键词没规划、页面互相抢词 | 分类页零点击;/skill/ 与 /audit/ 抢"安不安全"(已改) |
| **N 不稳定** | 计划页数天天变 | 按数据生成页面,过线出现、掉线消失;仓库删除变 404 | 存在:50 星、500 星两道门槛都会让页面进出 |
| **信号互相矛盾** | 站点地图、规范标签、noindex、内链说法不一 | 站点地图里列跳转页、noindex 页,lastmod 写假日期 | 今天修了:跳转页、假 lastmod、蓝皮书假日期 |

**最容易出事的时机**:批量上线程序化页面、改名或迁移、加筛选排序参数、删内容或调门槛、改模板、部署出 bug。每做一次这类改动,都该重看一次三个数。

### 对方补充的三条判断,对照我们的数据

| 判断 | 我们的情况 |
|---|---|
| N > M 太多,说明很多 N 没必要存在 | **成立。** 50–499 星的 skill 页占 N 的 55%,90 天只有 58 次点击 |
| N > X 太多,是抓取和内链问题 | **只对一半。** 8 月测过:37 条内链的场景页从没被抓,3 条内链的反而收录了。我们的瓶颈是抓取预算本身(约 110 页/天) |
| X > M 太多,是页面质量问题 | **成立,但"质量"的含义要说清。** 没收录的页和收录的页模板完全一样,差别在仓库热门程度:热门仓库在 Google 上已经有 GitHub 原页和官方文档,我们的页没提供额外信息 |

**补充一点**:noindex 不省抓取预算,Google 要先抓到页面才能看见 noindex。抓取量里有 40% 用在"发现新网址"上。

## 三、今天做的诊断

### 1. 零曝光页抽查(Search Console 网址检查,110 个网址)

| 组 | 结果 |
|---|---|
| 有曝光的 skill 页(对照,14) | 13 个已收录,全部近期抓过,规范页都是自己 |
| 零曝光 skill 页(58) | 已发现未收录 40%、Google 不知道 24%、已收录 21%、抓了不收 14%、软 404 2%;37 个从没被抓过 |
| compare 页(10) | **全部"Google 不知道"**,上线半年没被发现 |
| daily 页(9) | 一半已收录,其余多为近几天的新页 |
| 分类页(4) | 3 个已收录,只是没人搜 |
| audit 页(15,不在站点地图) | 10 个"Google 不知道" |

没有任何一页被判成 GitHub 的重复页。

### 2. 抓了不收的热门页 vs 已收录页(内容对比)

词数、标题数、FAQ 数、模板文字占比几乎相同(约 790 词、9 个 H2、5 条 FAQ、73% 非模板文字)。**唯一明显的差别是仓库星数**:不收的中位数 17,088 星,有曝光的 1,154 星。

### 3. 按星数分档的曝光(90 天)

| 星数 | 仓库数 | 有曝光的页 | 每页平均曝光 |
|---|---:|---:|---:|
| 50–200 | 7,686 | 2% | 0.3 |
| 200–500 | 2,876 | 4% | 1.0 |
| 500–1,000 | 1,385 | 25% | 4.5 |
| 1,000–5,000 | 1,661 | 33% | 9.6 |
| 5,000–20,000 | 487 | 29% | 11.3 |
| 20,000+ | 278 | 35% | 24.5 |

整体上星数越高,每页曝光越多。因此"优先放小众仓库进站点地图"的想法被否掉(那是我根据 9 个样本做的推测,全量数据相反)。500 星门槛上下差距明显,但分不清是"进了站点地图"还是"更热门"的作用。

## 五、没做的决定和原因

| 事项 | 状态 | 原因 |
|---|---|---|
| 50–499 星页面直接不生成(方案 B) | 暂缓 | 页面消失会产生上万个 404,Google 要几个月消化;先看方案 A 一两个月的效果 |
| compare 页撤下,合并进场景页 | 待定 | 11 页、0 点击、半年没被发现,影响小,可以随时做 |
| 站点地图选页规则改动 | 不改 | 数据支持现在的 500 星门槛 |
| 大规模补内链 | 不做 | 8 月的测量显示内链多少解释不了谁被抓 |
| /best/ 按业务分组建上级页 | 暂缓 | 要改 URL、做跳转,优先级排在后面 |
| 抓了不收的热门仓库页 | 未处理 | 原因是没有额外价值,模板改版(安装命令)算第一步 |

## 七、注意事项

- 抽查是 110 个网址的样本,比例有误差。
- "热门仓库因为没有额外价值而不被收录"是推断,没有被直接证实。
- 500 星门槛上下的差距,"进站点地图"和"仓库热门"两个因素重合,分不开。
- skill 页标题改版推翻了旧模板的设计。旧模板注释里写过理由:搜仓库名的人主要想去 GitHub,我们能额外提供的只有安全评级。所以要盯点击率,下降就回滚。

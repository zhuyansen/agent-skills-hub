# GEO fan-out 实测:agentskillshub.top 与 apiflux.ai(2026-10-14)

工具:JeffLi1993/open-growth-skills 的 chatgpt-fanout-queries(OpenAI Responses API,gpt-6.1-sol,强制联网搜索,每题一次)。
两站各 10 个买家问题。记录的是 API 的搜索轨迹,不等于 ChatGPT 网页版;每题只跑一次,有随机性。

## 结论

- **20 题里两个站一次都没出现**:没被引用,也没进搜索候选(每题候选 23–85 个网页)。
- 我们的 AI 来访来自别处:GA 近 90 天 AI 来源 183 次(占全站 0.67%),**Gemini 63、豆包 52**、ChatGPT 30、Perplexity 19、Claude 10、千问与元宝各 4。落地页:首页 34%,/best/ 场景页约 26%(code-review 15、ppt 13),**博客 0**。
- **agentskillshub 类问题,ChatGPT 引用:GitHub 仓库 43%、官方文档 25%、其他页面 15%、博客 11%、首页 6%。** 目录站里只有 skills.sh 被引用(2 次);Reddit 和 arXiv 出现在全部 10 题的候选里。
- **apiflux 类问题,ChatGPT 引用:文档 43%、定价页 20%、其他页面 14%、博客 14%、首页 6%、GitHub 3%。** 最常被引用:openrouter.ai 8 次、docs.litellm.ai 4 次、Anthropic 官方页。印证"AI 引用 docs 和 pricing,不引 blog"。
- apiflux 没有独立 /pricing 页;Search Console 近 90 天 /models 曝光 389、点击 0,/docs 曝光 204、点击 0,全站点击 37(品牌词 19)。apiflux 页面上的 GA 代码 G-EZ3XDZFWC9 不在本账号任何属性里,AI 来访无法统计。

## 建议

- apiflux:①独立 /pricing 页,每模型每百万 token 价格与官方价并排;②按问题写 docs 设置指南(Claude Code 接第三方 API、一个 key 调三家模型);③先查清 GA 代码归属。
- agentskillshub:①把 awesome-* GitHub 合集当主要 GEO 渠道维护;②Reddit 用真实回答进入。

The repository at ~/src is a design skill or tool for AI coding agents (a Claude Code skill or plugin, an MCP server, a CLI, or similar). Install it so that Claude Code can use it in a new session, following its own README:
- a skill or plugin: put it where Claude Code loads it (~/.claude/skills, ~/.claude/commands, ~/.claude/agents);
- an MCP server: install its dependencies and register it with `claude mcp add --scope user ...`;
- a package or CLI: install it.
Do not design anything yet. Do not ask questions. At the end print exactly one line: SETUP: done <what you installed> or SETUP: failed <reason>.
